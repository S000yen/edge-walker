# Edge Walker

画面のエッジ（作業領域の縁）を歩き回るレトロ風ミニゲームの常駐アプリ（Windows / C# / WinForms）．
他のウィンドウを操作している間も表示され，クリックは素通りします．

## ビルド
    winget install Microsoft.DotNet.SDK.10
    dotnet --version
    dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
出力: bin\Release\net10.0-windows\win-x64\publish\EdgeWalker.exe

## 操作
- タスクトレイ: 設定… / 一時停止(再開) / 今すぐ出す / 終了（ダブルクリックで設定）
- ホットキー: Ctrl+Alt+Shift+P 一時停止 / S 設定 / Q 終了
- キャラをクリック → 2分隠れる．ラウンド終了後も2分隠れる
- 全画面アプリ中，メモリ使用率が上限(既定50%)以上のときは自動で隠れる
- 設定は %APPDATA%\EdgeWalker\settings.json に保存
- モードは2つ：エッジモード（画面の縁を歩き回って追いかけっこ）とメイズモード（操作がないとき，画面いっぱいの迷路）．設定でそれぞれオン/オフできる．エッジをオフにすると普段は何も出ず，操作が60秒（設定可）なくなるとメイズだけが始まる．操作すると迷路もキャラも消えて，何も出ない状態に戻る．トレイの「今すぐ出す」は，エッジオフのときはその場でメイズを始める
- 複数のモニター: 設定画面の「表示するモニター」で，エッジ・メイズを出すモニターを選ぶ（既定はプライマリ）．選んだモニターが外されたら自動でプライマリになり，つなぎ直すと戻る．全画面アプリの検出も，そのモニターの上にあるときだけ
- 「適用」を押すと，ボタンの横に「✓ 適用しました」が3秒ほど出る
- 設定画面: メインには，モードごとに，エッジ（オン/オフ，ラウンド終了後・クリック後に消える時間），メイズ（オン/オフ，始まるまでの秒数），PC（モニター，Windows起動時の常駐，全画面アプリ中は隠す，メモリ使用率の上限）だけを出す．細かい数値は「詳細設定…」にタブ分け（速さ・難しさ／エッジ／メイズ／見た目）
- 主人公の加速: クッキーを食べた1ブロックだけ（`DotBoost`），反撃中（`PowerBoost`）．どちらも既定は0（加速なし）．加速している間は1ブロックの時間が縮み，ゴーストの実時間の速さは変わらない

## 画像（56枚）
`assets\*.png`（正方形・透過PNG，推奨32x32）．exeと同じ場所に assets フォルダを置くと差し替えできます（ない分は埋め込みの仮画像）．
一覧は `sheet\overview.png`（ファイル名と，sheet.png上の位置つき）．仮画像は `python make_assets.py` で作り直せます．

- 主人公 9枚: `player_{right,left,down,up}_{0,1}.png`（口 開／半開）＋ `player_closed.png`（口を閉じた球体．全方向で共通）
- ゴースト 32枚: `enemy_{red,pink,cyan,orange}_{right,left,down,up}_{0,1}.png`（0と1の足を1マスごとに交互に表示）
- おびえたゴースト 4枚: `scared_{blue,white}_{0,1}.png`（全員が青．効果が切れる前に，足の位置の途中で青⇔白に点滅）
- 誕生の11段階: `egg_0.png`〜`egg_10.png`（`egg_0` はミニボム．食べられたゴーストにも使う）
- 目玉は専用の画像なし．4色x2種類の足のゴーストで同じ色になっている部分（白目と瞳）を向きごとに抜き出して使う（起動後に1回だけ計算）．ゴーストの絵を差し替えれば目玉も変わる．4色で目が違う絵にすると共通部分が取れず，赤ゴースト全体が目玉になる
- 壁は画像ではなくプログラムで描画（白い角丸の細長い枠線）．クッキーと文字も同様

### スプライトシート（1枚にまとめる場合）
`sheet\sheet.png`（176x112）が見本です．exe の隣の `assets\sheet.png` に置くと，個別PNGより優先されます．
11列x7行で，1マスは正方形（幅=11マス，高さ=7マスなら何pxでも可）．
    行0: player_right_0/1 player_left_0/1 player_down_0/1 player_up_0/1 player_closed
    行1〜4: 赤・ピンク・水色・オレンジ．各行は 右0,1 左0,1 下0,1 上0,1
    行5: scared_blue_0/1 scared_white_0/1
    行6: egg_0 〜 egg_10

## ルール
- ゴースト4体（赤・ピンク・水色・オレンジ）が主人公から20〜60マスの範囲に，互いに3マス以上あけて出現．範囲の両端に壁があり，「start!」で消える
- 通常クッキーは先読みのマスに基本的に必ず出る（大きいクッキーだけ確率．通ったばかりの場所には出ない）
- 速さ: 主人公は1ブロック180ms固定（加速しない）．ゴーストは初速が主人公の0.90倍で，1分ごとに+0.2，最高1.06倍まで速くなる．反撃中は初速の半分，目玉は初速の1.5倍．エッジモードとメイズモードで共通で，モードが切り替わっても、その時点の速さのまま続く
- 初期値: 反撃30ブロック，ラウンド終了後30秒・クリック後2分で復活，文字の大きさ60%
- 誕生は11段階．食べたゴーストはミニボムになり，数ブロック後に消える
- タスクバーの設定・解像度・モニターが変わると，エッジを作り直す（自動非表示のタスクバーが一瞬出入りしても何も起きない）

## メイズモード（既定オン）
- キーボード・マウス操作が60秒（設定可）ないと，作業領域いっぱいに青い二重線の壁の迷路ができる．迷路はキャラ（主人公と各ゴースト）の周囲だけが見える
- 通路のほぼ全部にクッキーが並ぶ（大きいクッキーは10個）．全部食べれば勝ち．1試合は5分弱が目安，勝率は約6割
- 迷路は2種類ある（設定の「迷路の種類」で，ランダム／島型／格子型）．島型は壁のかたまりを並べた形，格子型は通路も壁も1マス幅で，曲がり角と交差点だけでできている．どちらも行き止まりはない
- 迷路の中の2x2の部屋が「ゴーストの家」．まわりは壁で，入口は1辺（2マス幅）だけ．主人公は入れない．白い壁が入口で，ゴーストが出入りするときだけ開く
- ゴーストは最初は家の中で，5ブロック後から10ブロックおきに1体ずつ出る．道を戻らず，分かれ道ではランダムに進む．主人公が8マス以内に近づくと，その方向を狙う（個性は設定でオフにできる）
- 食べられたゴーストは目玉になって迷路をたどって家へ戻り，着くとすぐ復活して，6ブロック後にまた出る．目玉に当たってもダメージはなく，目玉は倒せない
- 画面の左右の端どうし，上下の端どうしをつなぐワープがある（青緑の二重の輪が印．毎回位置が変わる）
- 主人公は捕まっても2回まで復活する．ゴーストから遠い場所に，誕生と同じ11段階の演出で生まれる．残りの命は画面左下の凹み（通れない2マス）に，左向き・口が半開きの主人公（`player_left_1`）を2つ並べて出す（使った分は消える）．通路の主人公と見間違えないよう，小さくして灰色の枠に入れる
- 主人公は，大きいクッキー中は近くのゴーストを追い，大きいクッキーをできるだけ避ける．ゴーストが近いと，先に着ける大きいクッキーを取りに行く
- 1試合が終わって10秒後に次の試合が始まる（操作がない間）．エッジのラウンドが終わったあとも，10秒空けてからメイズに入る．ラウンドの途中では入らない（終わっているか，隠れているときだけ）
- 操作があると壁が消え，残っているゴーストと主人公が一番近いエッジへ歩き，着いたものからエッジモードの追跡・逃走に入る．ゴースト4体とも参加する（家の中・目玉も含む）
- エッジモードが隠れている最中でも始まる．全画面アプリ・メモリ使用率が高いときは始まらない
- ゴーストの初速・加速・最高速，主人公の速さ，「近い」の距離・クッキーの割合・出る間隔などは設定画面から変えられる（目玉の速さは初速の何倍かも設定可）

## 注意
Windows実機では未検証です（ゲームロジックは単体テスト済み．画面部分はスタブでのコンパイル確認のみ）．
設定ファイルが古いと新しい既定値が反映されません．その場合は settings.json を消すか，設定画面で「標準に戻す」→「適用」．

## 軽さのための作り
- 画面への反映は，描画用のメモリ（DIBセクション）を最初に1回だけ作って使い回す．作れない環境では従来の方法に自動で切り替わる
- メイズの壁は，壁のかたまりごとに範囲を持ち，各キャラの視界にかかるものだけ描く
- 視界の端を薄くする処理は，メモリを直接書き換え，薄くする場所だけを処理する
- 目玉の画像は起動後に1回だけ作る．エッジは動いたキャラのある帯だけ描き直す
- ビルドには `AllowUnsafeBlocks` が必要（csprojに設定済み）

## exeのアイコン
`app.ico` が exe のアイコン．`player_right_0.png` から `python make_icon.py` で作る（画像を差し替えたら作り直して，再ビルド）．トレイのアイコンは実行時に画像から作るので，作り直しは不要
